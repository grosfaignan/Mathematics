# 5e — Fractions et signes — Exercice 001

## Consigne

Effectue chaque calcul et donne le résultat sous forme irréductible.

## Exercice 1

Calcule :

```text
7/12 - 5/18
```

## Exercice 2

Calcule :

```text
-3/5 + 7/10
```

## Exercice 3

Calcule :

```text
4/9 - (-5/6)
```

## Exercice 4

Calcule :

```text
-7/8 + 5/12 - 1/6
```

## Exercice 5

Calcule en respectant les priorités opératoires :

```text
2/3 - (5/4 × 8/15)
```

## Méthode attendue

Pour chaque calcul, indique les transformations importantes.

Exemple de présentation :

```text
1/2 + 1/3
= 3/6 + 2/6
= 5/6
```

**Attention :** les signes `+` et `-` font partie intégrante des nombres. Ne les supprime pas lors de la mise au même dénominateur.
