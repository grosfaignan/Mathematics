Il fallait répondre :

## Bilan pédagogique

### Note : 8/10

La distinction **périmètre / aire / volume** est globalement maîtrisée.

Deux erreurs apparaissent :

1. une erreur arithmétique isolée dans $10+16$ ;
2. une confusion importante entre les unités d'aire ($cm^2$) et de volume ($cm^3$).

La seconde erreur mérite une vérification ciblée, car la distinction entre dimensions est fondamentale :

- longueur → unité simple : $cm$ ;
- aire → unité au carré : $cm^2$ ;
- volume → unité au cube : $cm^3$.

Nous allons donc faire un **exercice ciblé court sur les unités et dimensions**, plutôt que de considérer immédiatement cette erreur comme une lacune durable.
